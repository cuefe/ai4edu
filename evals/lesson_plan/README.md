# 教案生成评测

- 用例：[cases.yaml](cases.yaml)，按人教版初中数学、英语挑选课题，覆盖新授、复习、习题、讲评课。
- 运行：在 `server` 目录执行 `uv run python ../evals/lesson_plan/run.py`（需要 `server/.env` 里的模型 Key，会产生少量调用费用）。
- 结果：`out/<时间>/`，每条用例一份 Markdown，`summary.md` 汇总自动检查结果。`out/` 不入库。

## 自动检查（`app/ai/skills/lesson_plan/checks.py`）

- 九个部分齐全（缺失通常是输出被截断）
- 教学过程各环节时长合计等于课时长度
- 没有引用教材页码（模型不知道真实页码，引用了多半是编的）

## 人工评分（每项 1–5 分，由任课老师或教研员打）

| 项 | 5 分的标准 |
|---|---|
| 目标 | 3～4 条，行为动词可检测，和课标核心素养对得上 |
| 内容准确 | 概念、例题、答案没有错误；英语例句地道、难度符合年级 |
| 环节设计 | 导入、新授、练习、小结完整，时间分配合理，学生活动充分 |
| 可操作性 | 关键提问有原话，例题练习完整，新老师能照着上课 |
| 作业 | 分层合理，总量不超过 20 分钟，有答案 |

改 prompt 或换模型时：同一批用例跑新旧两版，人工评分平均分不下降、自动检查通过率不下降，才能上线。改 prompt 要同时把 `PROMPT_VERSION` 加一。
