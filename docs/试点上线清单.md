# 试点上线清单

给 1–2 所种子学校或机构试点用。打 ☐ 的是上线前要做的事，标“需要你来办”的不是写代码能解决的。

## 1. 服务器（需要你来办）

- ☐ 服务器放在中国大陆（学生个人信息要存境内），2 核 4 G 起步，系统盘之外最好再挂一块数据盘放数据库和备份。
- ☐ 域名做 ICP 备案（大陆服务器必须），开 HTTPS。HSTS 在终止 HTTPS 的那一层（宿主机 Nginx 或 CDN）加。
- ☐ 向当地网信部门确认生成式人工智能服务的备案、登记要求（我们调用的是已备案的通义、DeepSeek 接口，面向学校提供服务时仍可能要登记）。学校要求等保二级的，按阿里云的等保方案准备。

## 2. 部署

```bash
cd deploy
cp .env.example .env        # 按注释填写：ENV=prod、三个随机密钥、POSTGRES_PASSWORD、模型 Key
docker compose up -d --build
docker compose run --rm api python -m app.cli migrate
docker compose run --rm api python -m app.cli create-platform-admin --name 运营 --phone 手机号 --password 密码
```

- ☐ `.env` 里 `ENV=prod`。生产模式下启动时会检查：密钥不是开发默认值、Redis 不是内存版、短信不是打印到日志。没开通短信时 `SMS_PROVIDER=none`：只能密码登录，危机预警只发站内信，不发短信。
- ☐ 经过 Cloudflare 等 CDN 时填 `CLIENT_IP_HEADER=cf-connecting-ip`，审计日志里才是真实 IP。
- ☐ `docker compose exec web nginx -t` 检查配置；`curl -I https://域名/` 能看到 `Content-Security-Policy`、`X-Frame-Options` 等安全响应头。
- ☐ 在试点服务器上压一次（见 [压测记录](压测记录.md)）：`seed-load` 只能在非生产环境用，可以先用 `ENV=dev` 起一套压测，压完删掉数据卷再按生产配置部署。

## 3. 开通学校

- ☐ 平台运营后台 → 套餐：建好要卖的套餐（学生名额、老师名额、每月 AI 额度、服务期）。
- ☐ 机构管理 → 开通机构：选套餐（名额、额度、到期日会自动带出，可以改），填机构管理员手机号和初始密码。
- ☐ 机构管理员登录 → 学生管理里下载模板、批量导入学生（初始密码导入后只显示一次，要下载保存）；建班级、加老师、把老师加到班级里。
- ☐ 学生首次登录会被要求改密码。机构管理员在“机构概况”里能看到名额、到期时间和本月 AI 用量。

## 4. 备份

- ☐ 把 `deploy/backup.sh` 加进 crontab（每天凌晨，保留 14 天），手动执行一次确认能生成 `db-*.dump` 和 `files-*.tar.gz`。
- ☐ 做一次恢复演练：在另一台机器或另一套 compose 上按脚本注释里的步骤恢复，确认能登录、能看到数据。
- ☐ 定期把备份拷到服务器之外（对象存储或另一台机器）。

## 5. 每天看什么

- 外部监控探测 `https://域名/api/health`，挂了发短信或钉钉（需要你来办：用云监控或 UptimeRobot 之类）。
- 平台运营后台：
  - **AI 用量**：费用、失败次数。某个模型失败多，可能是下线了，改 `server/app/ai/gateway/models.yaml`。
  - **内容安全**：被拦下的消息、危机信号；各学校的危机预警有没有超时没处理的。
  - **审计日志**：登录失败、改分、导出、停用账号、改机构额度。
- 机构的 AI 额度用到 80% 时提前联系学校（目前没有自动提醒）。

## 6. 学校那边（需要你来办）

- ☐ 隐私政策、用户协议：请法务起草，说明收集哪些信息、AI 怎么用、保存多久、怎么删除。
- ☐ 监护人同意：试点阶段由学校线下收集（家长端是下一期）。
- ☐ 给老师做一次培训：备课、出题审核、布置作业、批改确认、心理预警处理（老师必须在“心理预警”里填写处理记录）。
- ☐ 定好反馈渠道（微信群），每周收一次问题。

## 已知限制

- 没有短信通道时，危机预警只有站内信；高风险预警建议学校另外约定电话联系。
- 问一问每个学生每天最多 200 条；老师每天最多发起 60 次 AI 生成（教案、讲义、背诵卡片、出题）。在 `deploy/.env` 的 `TEACHER_DAILY_AI_TASKS`、`STUDENT_DAILY_TUTOR_MESSAGES` 里可以调。
- 机构到期、停用后，已经登录的设备最多 30 分钟后退出（登录令牌的有效期）。
